61번 기준으로 릴레이 토글 변수를 아무리 줄여도 0.078초 off가 최소임
즉 1 frame을 그 밑으로 쪼갤수없음

따라서 dsp_engine.py도 함께 수정하여 sub-frame을 다룰수있게 수정함
또한 socket_orchestrator_v2.py에서 아래처럼 설정하였음.

####################################################
# --- OFF 측정 = 단일 서브프레임 (TV 재부팅 방지 핵심 노브) ---
RESCAN_OFF_SAMPLES = 64       # OFF 측정 샘플 수. 32의 배수 권장(fs/n=60Hz bin 정렬). 64≈33ms.
                              # TV 재부팅 시 ↓(32≈17ms). H1 신뢰 위해 최소 32 권장(16 이하 = H1 0).
RESCAN_OFF_SETTLE_S = 0.005   # OFF 후 측정 전 안정화(rescan 전용, 짧게). 체류 더 줄이려면 ↓(0 가능).
####################################################

이렇게하여 tv가 재부팅 안됨.

하지만 청소기가 꽂혀만 있고, 드라이기가 켜져있을때 TV를 재스캔하면 충전기로 오인식됨.
