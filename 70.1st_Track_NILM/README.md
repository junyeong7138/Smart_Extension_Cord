2번 코드: 하드웨어(FPGA)가 수집한 FFT 파일은 과감히 무시하고, 모든 데이터(단일/합성)를 실전(ai_extension)과 똑같은 파이썬 소프트웨어 FFT로만 통일해서 추출하도록 로직을 변경합니다.
